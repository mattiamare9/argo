# ADR-007 – React e TypeScript

**Stato:** Accettato
**Origine:** Specifica architetturale v1.0

## Decisione

Frontend React + TypeScript + Vite.

## Motivazione

Interfaccia amministrativa moderna e indipendente dal backend.

## Conseguenze

Nessun Streamlit. Il frontend parla solo con le API del backend.
